# AI-generated assets

Fernpeak Outfitters is a fictional store, and all of its product photography and hero carousel slides are AI-generated. Nothing in `data/images/` is a photograph of a real product or place.

| Field       | Value                                                                                                                                                                              |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tool        | Codex (image generation)                                                                                                                                                           |
| Date        | 2026-10-15 (generation date)                                                                                                                                                       |
| Files       | 36 JPEG files in [`data/images/`](../data/images/): 30 product images, one per colour variant, and 6 carousel slides (desktop and mobile versions of 3 slides)                     |
| Source data | [`data/images/prompts.json`](../data/images/prompts.json) holds the text description of every file; [`data/images/brief.md`](../data/images/brief.md) is the same data for reading |
| Variants    | Other colours of a product were made by editing the base image of that product, so shape, angle and framing stay the same                                                          |
| Sizes       | Product images 3000×3750 px, slides 3840×2160 px (desktop) and 1800×2250 px (mobile)                                                                                               |

The product video and its poster are not AI-generated; see [`third-party-assets.md`](third-party-assets.md).
